# 📈 Graph Plotter

An interactive and responsive graph plotting web application built using pure HTML, CSS, and JavaScript.

This tool allows users to create dynamic line charts, visualize time-series data, import/export CSV files, customize graph styles, and print charts directly from the browser.

---

## ✨ Features

- 📊 Interactive SVG-based graph plotting
- ⏳ Time-series graph mode
- 📁 CSV Import & Export
- 🎨 Custom line styles (solid, dashed, dotted)
- 🔵 Adjustable point sizes
- 🖨️ Print-ready charts
- 📱 Fully responsive UI
- 🖱️ Crosshair hover tracking
- 📝 Custom chart labels and titles
- ⚡ Real-time plotting updates
- ➕ Add/remove data rows dynamically

---

## 🚀 Demo Features

### Normal Graph Mode
- Plot X/Y values manually
- Add notes to graph points
- Customize chart appearance

### Time Graph Mode
- Auto-generate date rows
- Daily progression plotting
- Timeline-based visualization
